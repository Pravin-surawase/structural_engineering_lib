Task: XLL-P0-WINDOWS-PACKAGING-RUNTIME-SPIKE

Objective

Create and prove the smallest viable commercial Excel-DNA XLL for StructAutomate on Windows.

The intended product is one x64 XLL loaded into desktop Excel. It creates a native StructAutomate Ribbon tab and runs product C# code inside Excel. No companion host, Python installation, Node server, WebView2, installer, ETABS connection, solver or engineering-function migration is permitted in this P0 task.
