## 📋 Guidelines

| Action | When To Use |
|--------|-------------|
| **Add here** | Multi-session document drafts |
| **Move out** | When document is complete → permanent location |
| **Review** | Weekly - clean up stale work |

---

## 🔄 Workflow

```
1. Create draft in _active/
2. Work on it across sessions
3. When complete, move to permanent location:
   - Guides → docs/getting-started/ or docs/cookbook/
   - Research → docs/research/
   - Architecture → docs/architecture/
   - Reference → docs/reference/
4. Delete from _active/
```
