# Learning Foundations — Software Engineering from Zero

**12 modules** that teach you everything about how real software projects work — from "what is architecture?" to "how do I start my next project from scratch?"

These are NOT specific to this repo. They are universal concepts every developer needs.

## Who This Is For

A developer who can write code but hasn't built a full project before. You know Python/JS syntax but not how real teams organize, test, deploy, and maintain software.

## How to Read

- **Read in order** — each module builds on the previous
- **Module 12 is the capstone** — it ties everything together into a practical "start a project" guide
- Each module has: concepts → examples → diagrams → exercises → things to know
